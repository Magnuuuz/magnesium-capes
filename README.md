# Magnesium Capes Registry

Dieses Repository ist die öffentliche Registry für Magnesium-Custom-Capes.

- Spieler-Capes und Manifest liegen unter `magnesium/`:
  - Capes: `magnesium/capes/*.png` (64x32, Vanilla-Cape-Layout)
  - Manifest: `magnesium/registry.json`
- Die Registry-URL, die Freunde im Magnesium-Client unter **Mods > Capes > Registry URL** eintragen:
  `https://raw.githubusercontent.com/Magnuuuz/magnesium-capes/main/magnesium/registry.json`
- Newer Capes und Spieler-Zuordnungen werden automatisch durch den Magnesium-Client (GitHub-Auto-Publish) gepusht.
